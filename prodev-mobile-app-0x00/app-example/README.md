# App Example (Expo Router)

This folder contains the starter Expo Router example that was generated during scaffolding. It is useful as a reference for layout structure, navigation, and example screens.

## How This Folder Was Created

The Expo template is moved here when running the reset command:

```bash
npm run reset-project
```

That command moves the original starter app to `app-example/` and creates a fresh `app/` directory for new development.

## What You Can Do Here

- Inspect the example routing structure
- Compare with your current `app/` folder
- Copy patterns for tabs and layouts

## Run the Example (Optional)

If you want to run the example, ensure your `app/` folder is empty or moved elsewhere, then start the dev server:

```bash
npx expo start
```

Open the app in Expo Go, a development build, or an emulator as usual.
